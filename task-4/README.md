# Task 4: Responsive Design Tokens & Mobile-First CSS

## Overview
This task implements a responsive design system using CSS custom properties and a mobile-first CSS architecture.

## Features
- CSS design tokens for colors, typography, spacing, and border radii.
- Responsive layouts for mobile, tablet, laptop, and desktop screens.
- Breakpoints for 320px, 768px, 1024px, and 1440px.
- Glassmorphism effects and box shadows.
- Hover transitions and interactive styling.
- Dark and light theme variables.
- Reduced-motion accessibility support.
- Responsive tables, forms, and dashboard components.

## Files
- `style.css` — design tokens and responsive styles.
- `../screenshots/` — responsive design screenshots.

## Testing
The dashboard was previewed using Chrome DevTools responsive mode at a 320px mobile width. Additional responsive screenshots are included in the repository.

## How to Use
The stylesheet is linked from the Task 3 HTML pages:

```html
<link rel="stylesheet" href="../task-4/style.css">
```
